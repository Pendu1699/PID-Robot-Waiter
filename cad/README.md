# CAD

Mechanical design files: arm links, joint gearboxes, wrist and end effector, mast mount, base chassis.

Suggested convention:
- `cad/<part>/` per subassembly (e.g. `arm-shoulder/`, `base/`)
- Commit source files (Fusion `.f3d`, Onshape link, or `.step`) **and** `.stl` exports for printing
- Note the print settings (material, infill, layer height) in each folder's README
