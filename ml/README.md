# ML (plate & obstacle detection)

Training scripts and notes for the YOLO detector used at the pickup station.

- Datasets live **outside** this repo (Roboflow / Google Drive). Only small samples go here.
- Train in Colab, export to ONNX/NCNN, and copy the exported model to the Pi.
